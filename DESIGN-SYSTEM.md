# Design System

## 1. BRAND IDENTITY
- **Logo**: Do not redesign, modify, recolor, or distort the existing BIC logo.
- **Theme**: Premium Saudi Industrial Corporation + Engineering, Construction, Industrial Supply.
- **Vibe**: Modern, sophisticated, industrial, architectural, spacious, high-end. Avoid cheap templates, excessive rounded corners, excessive gradients, crowded layouts.

## 2. COLORS
- **Primary BIC Red**: Used for CTAs, active navigation, highlights, small accents. (Extract exact value from logo).
- **Deep Charcoal**: `#111111` (Headings, primary high-contrast text)
- **Industrial Charcoal**: `#242424` (Secondary backgrounds, cards, footer)
- **Off White**: `#F7F7F5` (Page backgrounds, alternate sections)
- **White**: `#FFFFFF` (Card backgrounds, clean space)
- **Steel Gray**: `#8A8F94` (Muted text, metadata)
- **Light Gray**: `#ECECEC` (Borders, dividers, subtle active states)

## 3. TYPOGRAPHY
- **Primary Font**: Manrope, Inter, or a similar professional sans-serif.
- **Arabic Font**: High-quality Arabic-compatible modern font (e.g., Cairo, Tajawal, or IBM Plex Sans Arabic).
- **Rules**:
  - Maintain strong hierarchy.
  - Good readability, proper line height, and controlled letter spacing.
  - Avoid excessive font weights.

## 4. LAYOUT & CONTAINERS
- **Max Width**: 1440px - 1600px for desktop content containers.
- **Sections**: Use full viewport width for visual sections (backgrounds/images), but contain text/editorial content.
- **Spacing**: Use excellent whitespace. Asymmetric layouts are welcome if they look editorial.
- **Responsive**: Mobile must feel intentionally designed, not just scaled down. Breakpoints: 1440+, 1280, 1024, 768, 480, 375.

## 5. UI ELEMENTS
- **Buttons**: Clear CTAs, accessible focus states, subtle hover interactions (no excessive animations).
- **Images**: High-quality industrial imagery. Do not use generic AI-looking visuals. Use controlled CMS images.
- **Icons**: Use a stable bundled/local icon library (e.g., Lucide). No excessive icons.
